## Your two photos
Use exactly these filenames inside `assets/`:

- `photo1.jpg` = last birthday wish/photo
- `photo2.jpg` = photo of both of you

`photo2.jpg` is also used as a very subtle, darkened background memory across the website.

## Other files
Optional:
- `music.mp3` = background music
- `voice.mp3` = your recorded birthday message

## GitHub Pages
1. Create a public repository, e.g. `for-moti`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose **main** and **/(root)**.
6. Save.
7. Wait for GitHub to publish the site.

The password is a fun unlock, not real security.
